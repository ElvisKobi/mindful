# Mindful — Reclaim Your Attention

Anti-doom-scrolling web app built with React JS, Supabase, and Tailwind CSS.

## Live App
https://mindful-ub9p.vercel.app

## Phase 1 — Complete ✅
- React JS + Vite + TypeScript
- Tailwind CSS v3
- React Router v6
- Zustand state management
- Supabase Auth + PostgreSQL
- Today, Goals, Reflect screens
- Block screen + breathing exercise
- PWA manifest
- Deployed to Vercel

## Tech Stack
- Frontend: React 18 + Vite + TypeScript
- Styling: Tailwind CSS v3
- State: Zustand
- Backend: Supabase (PostgreSQL + Auth)
- Hosting: Vercel

## Getting Started
1. Clone the repo
2. Run `npm install`
3. Create `.env.local` with your Supabase credentials
4. Run `npm run dev`
